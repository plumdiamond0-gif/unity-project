UI 시스템

UI 시스템은 UIManager를 중심으로 모든 UI를 관리하는 구조로 설계하였다. 각 UI는 기능별로 독립된 패널로 구성하였으며, 공통 기능은 PanelBase를 통해 관리하여 코드의 재사용성과 유지보수성을 높였다. 또한 Addressables를 이용해 필요한 UI를 동적으로 생성하도록 구현하여 메모리 사용을 최적화하였다.

UIManager

UIManager는 UI 생성과 관리를 담당하는 최상위 클래스이다.

게임에서 UI가 필요할 경우 Addressables를 통해 프리팹을 로드한 후 생성하며, 생성된 UI를 Canvas의 자식으로 등록한다. 이를 통해 UI 생성 방식을 일원화하고, 다른 시스템에서는 UIManager만 호출하면 필요한 UI를 사용할 수 있도록 설계하였다.

PanelBase

모든 UI 패널은 PanelBase를 상속받도록 구현하였다.

PanelBase에서는 모든 패널에서 공통적으로 사용하는 기능(패널 생성, 표시, 숨김 등)을 관리하며, 각 패널은 자신만의 기능만 구현하도록 역할을 분리하였다.

이를 통해 동일한 코드를 반복 작성하지 않아도 되었으며, 새로운 UI 패널을 추가할 때도 PanelBase를 상속받는 것만으로 공통 기능을 사용할 수 있도록 하였다.

HUD

HUD는 게임 플레이 중 항상 표시되는 정보를 관리한다.

구성 요소는 다음과 같다.

HealthBar : 플레이어 체력 표시
AttackGaugeBar : 공격 쿨타임 표시
InventorySlot : 현재 보유 아이템 표시
MiniMap : 현재 맵 정보 표시
ExpBar : 경험치 표시
ChosenWeaponData : 현재 장착한 무기 정보 표시

각 UI는 필요한 데이터만 받아와 화면을 갱신하도록 구현하여 서로 독립적으로 동작하도록 설계하였다.

Weapon Panel

무기 관련 UI는 UpgradePanel과 UnlockPanel으로 분리하였다.

UpgradePanel

현재 선택한 무기의 정보를 표시하고 강화 기능을 담당한다.

구성 요소

WeaponImage
WeaponButtons
UpgradeResultList
UpgradeButton
CostList

무기를 선택하면 WeaponPrefabTable에서 데이터를 받아와 현재 능력치와 강화 결과를 표시한다.

UnlockPanel

아직 획득하지 않은 무기의 정보를 표시하고 잠금 해제를 담당한다.

구성 요소

WeaponImage
Previous / Next Button
UnlockCostList
UnlockButton

잠금 해제 가능한 무기를 탐색하고 필요한 재화를 확인한 후 무기를 해금할 수 있도록 구현하였다.

기타 패널
InventoryPanel : 플레이어 인벤토리 관리
DeathPanel : 게임 오버 화면 출력

각 패널은 서로 독립적으로 동작하며 필요한 경우에만 생성 또는 활성화된다.

설계 의도

UI 시스템은 기능별 패널 분리와 공통 기능의 재사용을 목표로 설계하였다.

UIManager를 통해 UI 생성 방식을 일원화하였다.
PanelBase를 이용해 공통 기능을 재사용하도록 구현하였다.
Addressables를 활용하여 필요한 UI만 동적으로 생성하도록 하여 메모리 사용량을 줄였다.
각 UI가 자신의 역할만 수행하도록 구성하여 시스템 간 결합도를 낮추고 유지보수성과 확장성을 높였다.
한 가지 보완하면 더 좋을 부분

예전에 네 코드를 보면 UIManager가 CreatePanel<T>() 같은 방식으로 제네릭을 이용해 패널을 생성하고 있었어. 만약 그 구조를 그대로 사용 중이라면 기술명세서에 아래 내용을 한 문장 추가하면 설계 수준을 더 잘 보여줄 수 있어.

UI 생성은 제네릭 기반 생성 함수를 통해 구현하여 패널 종류와 관계없이 동일한 방식으로 생성할 수 있도록 하였으며, 코드 중복을 줄이고 새로운 UI 추가를 용이하게 하였다.

이 문장은 네 UI 시스템의 재사용성과 확장성을 잘 드러내기 때문에 면접에서도 좋은 설명 포인트가 될 수 있다.

















UIManager : 모든 UI들을 독립적인 패널 형식으로 관리하며 씬에 있는 Canvas를 받아와 그 자식으로 패널들을 생성한다.
Addressables를 이용해 UI를 필요할 때마다 동적으로 생성해 메모리 사용을 최적화했다.
Action을 사용해 PanelPlayer가 생성됐을 때 그 안의 UI 값들을 가져와 실제 씬에 있는 Player에게 값을 전달해준다.

PanelPlayer(HUD) : 필요할 때만 나오고 사라지는 다른 UI들과는 다르게 아래의 UI들은 전투 중에 항상 
화면에 띄워져 실시간으로 변경사항이 적용돼야 하므로 관리를 쉽게 하기 위해 HUD로 묶었다.
-HealthBar : 플레이어 체력 표시
-AttackGaugeBar : 공격 쿨타임 표시
-InventorySlot : 현재 보유 아이템 표시
-MiniMap : 현재 맵 정보 표시
-ExpBar : 경험치 표시
-WeaponData : 현재 장착한 무기 정보 표시

PanelBase : 모든 패널들이 공통으로 상속받고 있는 클래스로 이를 통해 
페이드 인, 슬라이드 인과 같은 연출적 공통 기능들을 처리했다.

PanelWeaponUpgrade : 무기 업그레이드에 관한 UI들을 관리하고, WeaponButton에서 무기 데이터를 전달받아 다른 UI에게 명령을 전달해준다.
-WeaponImage : 현재 선택된 무기의 이미지를 띄운다.
-WeaponButtons : 입력값을 감지하고 PanelWeaponUpgrade을 통해 저장된 무기 타입에 해당하는 데이터를 다른 UI들에게 넘겨준다.
-UpgradeResultList : SaveManager에서 현재 무기의 레벨을, WeaponPrefabTable에서 무기의 업그레이드 결과 데이터를 가져와 무기가 업그레이드될 시의 결과값을 띄운다.
-UpgradeButton : 플레이어가 지닌 자원이 충분한지 확인해 업그레이드 가능 여부를 검사한다.
-CostUI : 무기의 레벨과 무기 업그레이드 가격 데이터를 가져와 필요한 자원의 수량을 화면에 띄운다.

PanelUnlock : 무기 잠금해제에 관한 UI들을 관리하고, 플레이어가 무기 탭을 넘겼을 때의 UI들 초기화를 담당한다.
-WeaponImage : 현재 무기 이미지 띄움
-Previous / Next Button : 무기 탭 이동
-UnlockCostList : WeaponPrefabTable에서 잠금해제 비용 가져와 표시
-UnlockButton : 잠금해제 비용과 아이템 수 비교해 여부 검사

InventoryPanel : SaveManager 참조해 현재 보유한 아이템 수 표시

DeathPanel : 플레이어가 죽을 시 띄워지며 플레이어를 우주선기지 씬으로 보냄.

GameManager는 게임의 전체적인 실행을 위한 핵심 매니저들의 관리,생성 그리고 초기화를 담당합니다.
또한 Singleton 패턴을 기반으로 구현돼 씬이 바뀌어도 그대로 남아있고 게임 전체에서 하나의 객체만 생성되며 어느 클래스에서도 접근할 수 있습니다.
GameManager를 제외한 다른 핵심 매니저들은 GameManager의 자식 오브젝트로 붙여져 마찬가지로 게임에서 중복되지 않습니다.
모든 매니저들은 각자 주어진 하나의 역할만 수행하게 해 상호 간의 결합도를 낮추고 새로운 기능을 추가하기 쉽게 설계하였습니다.

AssetManager는 Addressable를 통한 비동기 로딩으로 에셋들을 필요할 때마다 로딩해주고 재사용하게 하는 역할을 한다.
다른 곳에서 필요한 에셋의 타입(제네릭 T), 주소(Address), 로딩 후 실행할 함수(callBack)를 넘겨준다면 그에 맞는 에셋을 찾아 그 에셋이 로딩될 때까지 비동기로 기다리고 끝나면 callBack을 실행한다. 만약 해당 에셋이 이미 로드 중이라면 완료될 때까지 기다려준다.
로드한 에셋이 더 이상 게임에서 필요하지 않게 되면 Release를 통해 참조를 해제한다.
