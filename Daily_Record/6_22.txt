제너레이터에 플레이어값 알리기 :

1.Start()에서 바로 찾기 : 

맵 생성 (Generator들도 같이 생성됨)
플레이어 생성

이라서 Generator.Start() 시점에는 플레이어가
아직 없을 수 있음. 타이밍 문제 나기 쉬움.





2.게이매니저에 플레이어 저장
Generator:
Transform playerTrans;
if(playerTrans == null && GM.GetPlayerTransform() != null)
{
    playerTrans = GM.GetPlayerTransform();
}

장점:
Generator 전체를 순회 안 해도 됨
각 Generator가 필요할 때 가져감
결합도 낮음




3.플레이어 생성 시 Generator들에게 알려주기
Generator[] generators = FindObjectsByType<Generator>(FindObjectsSortMode.None);
foreach(var generator in generators)
{
    generator.SetPlayer(player.transform);
}

단점:
플레이어 respawn 때 다시 돌려야 함
Generator가 많아지면 귀찮음



4.이벤트***
public class GameManager : MonoBehaviour
{
    public static Action<Transform> OnPlayerSpawned;
}

void Awake()
{
    GM.OnPlayerSpawned += SetPlayer;
}

void OnDestroy()
{
    GM.OnPlayerSpawned -= SetPlayer;
}

void SetPlayer(Transform tr)
{
    playerTrans = tr;
}

GameObject player = Instantiate(playerPrefab);
GM.OnPlayerSpawned?.Invoke(player.transform);

플레이어가 생성됐다는 사실을 방송(Broadcast)하고, 필요한 애들이 그 방송을 듣는다

만약 전부 직접 찾아다니면:

PlayerSpawner -> Generator 전부 찾아서 전달
PlayerSpawner -> Camera 찾아서 전달
PlayerSpawner -> UI 찾아서 전달
PlayerSpawner -> Enemy 전부 찾아서 전달


이벤트 쓰면:

PlayerSpawner
   ↓ (플레이어 생성됨!)
Broadcast
   ↓
Generator 듣기
Camera 듣기
UI 듣기
Enemy 듣기

플레이어 스포너는
“누가 듣는지 신경 안 써도 됨.”


*반드시 해제
오브젝트가 파괴됐는데 이벤트에 남아 있으면:
null reference
memory leak
이상한 버그
생길 수 있음.

    bool isMoving = MovementX != 0 || MovementY != 0;
//움직이고 있을 때

    if (isMoving && !isWalkingSoundPlaying && isGrounded)
    {
        if (isSprint)
//달리고 있다면
            walkAudio.Play();
//여기서 walkAudio는 loop가 아닌 단발성 오디오
//업데이트에서 연속적으로 실행되기에 뛰는 것처럼 들림
        else
//걷고 있다면(달리는 게 아니라면)



            if (walkRoutine == null)
//걷기루틴 초기화
        {
            walkRoutine = StartCoroutine(walk());
//새로운 코루틴 넣기
        }

//->이렇게 하는 이유 : 그냥 걸을 때마다 코루틴 한번씩 실행하기만 하면 걷다가 멈추고 다시 걸을 때마다 코루틴 중첩 현상 발생
//실행한 코루틴을 저장해서 멈출 때마다 기존 코루틴 초기화


        isWalkingSoundPlaying = true;
    }


    else if (!isMoving && isWalkingSoundPlaying || !isGrounded)
//움직이고 있지 않을 때나 공중에 있을 때
    {
        walkAudio.Stop();
        if(walkRoutine != null)
        StopCoroutine(walkRoutine);
        walkRoutine = null;
        isWalkingSoundPlaying = false;
    }

}


IEnumerator walk()
//걷기 루틴
{
    while(!isSprint)
    {
        _walkAudio.Play();
        yield return new WaitForSeconds(0.8f); 
//0.8초 간격으로 오디오 실행해서 걷는 것처럼 들림(업데이트에서 계속 실행하는 것보다 텀 김)
    }
    walkRoutine = null;
}
