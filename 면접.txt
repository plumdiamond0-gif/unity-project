{
객체(Object) : 

정의 : 
-메모리에 존재하며 데이터를 가지고 있고, 필요하면 기능도 수행할 수 있는 모든 것들
-넓은 의미 : UnityEngine.Object을 상속받는 모든 것들
-게임에서의 : GameObject
-C#에서의 : new를 통해 생성된 것들
-그 외 : GameObject != 객체 -> GameObject는 객체의 한 종류. 컴포넌트 또한 객체임

역할 : 
-하나의 실행 단위로 자신의 데이터와 기능을 가지고 다른 객체들고 협력해 프로그램을 동작시킴
-데이터 저장 : 자신의 상태를 지님
-기능 수행 : 데이터를 이용해 행동
-다른 객체와 상호작용 : 여러 객체가 서로 메서드를 호출함
-객체 지행에서의 : 자신의 책임을 수행하는 것. 필요한 경우 협력.

}

-------------------------------------------------------------------------------------------------

{
클래스(class) : 

정의 :
-객체의 속성(데이터)과 행동(기능)을 정의하여 객체를 생성하기 위한 설계도인 사용자 정의 자료형

역할 : 
-상태(State) : 객체가 어떤 데이터를 가지는가 
-행동(Behavior) : 객체가 무엇을 할 수 있는가
