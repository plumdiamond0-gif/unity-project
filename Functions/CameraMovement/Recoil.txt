이 반동 시스템은 FPS/TPS에서 많이 사용하는 **Target Rotation 방식의 카메라 반동 시스템**이다. 핵심은 **현재 회전값과 목표 회전값을 분리**하여 관리하는 것이다.

---

# 반동 시스템 (Recoil System)

## 개요

반동 시스템은 총기 발사 시 카메라를 순간적으로 회전시켜 사격의 타격감을 표현하는 기능이다.

반동은 **목표 회전값(Target Rotation)** 과 **현재 회전값(Current Rotation)** 을 별도로 관리하며, 보간(Lerp, Slerp)을 이용하여 자연스럽게 반동이 발생하고 원래 위치로 복귀하도록 구현하였다.

---

# 시스템 구조

```text
Fire()

↓

Target Rotation 증가

↓

Current Rotation이 Target Rotation을 따라감

↓

Target Rotation이 0으로 복귀

↓

Current Rotation도 원래 위치로 복귀
```

---

# 1. 반동 발생

총을 발사하면

```csharp
FireRecoil(...)
```

이 호출된다.

```csharp
_targetRotation += new Vector3(
    -recoilX,
    Random.Range(-recoilY, recoilY),
    Random.Range(-recoilZ, recoilZ)
);
```

여기서는 카메라를 **즉시 회전시키는 것이 아니라**, 목표 회전값(`_targetRotation`)에 반동 값을 더한다.

예를 들어

```text
발사 전

Target Rotation

(0,0,0)
```

한 발 발사하면

```text
(-5,1,-0.5)
```

가 되고

두 발 연속 발사하면

```text
(-10,0.5,-0.2)
```

처럼 계속 누적된다.

이 방식은 연사 시 반동이 자연스럽게 커지는 효과를 만든다.

---

# 2. 반동 방향

반동은 세 축으로 구성된다.

### X축

```csharp
-recoilX
```

위쪽으로 총이 튀는 반동이다.

FPS에서 가장 기본적인 반동이다.

---

### Y축

```csharp
Random.Range(-recoilY, recoilY)
```

좌우 흔들림이다.

매 발사마다 랜덤하게

```text
←

또는

→
```

방향으로 흔들린다.

---

### Z축

```csharp
Random.Range(-recoilZ, recoilZ)
```

카메라의 Roll 회전이다.

화면이 약간 기울어지는 효과를 준다.

---

# 3. 목표 회전 복귀

발사가 끝나면

```csharp
_targetRotation = Vector3.Lerp(
    _targetRotation,
    Vector3.zero,
    returnSpeed * Time.deltaTime
);
```

가 실행된다.

Lerp를 이용하여

```text
Target Rotation

↓

(5)

↓

(3)

↓

(1)

↓

(0)
```

처럼 목표 회전이 점점 0으로 감소한다.

즉,

반동 자체가 천천히 사라진다.

---

# 4. 현재 회전 보간

실제 카메라에는

```csharp
_currentRotation = Vector3.Slerp(
    _currentRotation,
    _targetRotation,
    snappiness * Time.deltaTime
);
```

이 적용된다.

Current Rotation은

Target Rotation을 따라간다.

예를 들어

```text
Target

10°
```

이면

```text
Current

0°

↓

4°

↓

7°

↓

9°

↓

10°
```

처럼 부드럽게 회전한다.

즉

반동이 순간이 아니라

빠르게 튀어 오르는 느낌을 만든다.

---

# 5. 최종 반동 적용

LateUpdate에서

```csharp
transform.rotation *= Quaternion.Euler(_currentRotation);
```

을 수행한다.

즉

기본 카메라 방향

*

현재 반동 회전

을 합쳐 최종 카메라 회전을 만든다.

---

# 6. 무기별 반동 설정

각 무기는 ScriptableObject에서

* Recoil
* Snappiness
* Return Speed

를 가진다.

따라서

권총

↓

빠른 복귀

↓

작은 반동

샷건

↓

큰 반동

↓

느린 복귀

기관총

↓

작은 반동

↓

빠른 Snappiness

처럼 코드 수정 없이 다양한 무기의 반동 특성을 설정할 수 있다.

---

# Lerp와 Slerp를 분리한 이유

이 시스템의 핵심은 **반동의 목표와 실제 움직임을 분리했다는 점**이다.

* `Lerp`는 **목표 회전값(Target Rotation)** 을 원래 상태(`Vector3.zero`)로 서서히 되돌리는 역할을 한다.
* `Slerp`는 **현재 회전값(Current Rotation)** 이 목표 회전값을 부드럽게 따라가도록 만들어 실제 카메라 움직임을 자연스럽게 표현한다.

이처럼 두 단계를 분리함으로써, **반동이 즉시 발생하는 듯한 반응성과 부드러운 복귀 움직임을 동시에 구현**할 수 있다.

---

# 주요 특징

* 목표 회전값과 현재 회전값을 분리하여 자연스러운 카메라 반동을 구현하였다.
* X축은 상하 반동, Y축과 Z축은 난수를 이용한 좌우 및 Roll 반동을 적용하여 반복적인 움직임을 방지하였다.
* `Vector3.Lerp()`를 사용하여 목표 회전값을 점진적으로 원래 위치로 복귀시켰다.
* `Vector3.Slerp()`를 사용하여 현재 회전값이 목표 회전값을 부드럽게 따라가도록 구현하였다.
* 무기별 `Recoil`, `Snappiness`, `Return Speed`를 데이터화하여 코드 수정 없이 다양한 반동 특성을 설정할 수 있도록 설계하였다.
