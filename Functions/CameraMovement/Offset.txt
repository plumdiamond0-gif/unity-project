포트폴리오에서는 단순히 "거리 저장"이라고 쓰기보다 **왜 필요한지**와 **어떻게 사용되는지**까지 설명하면 좋습니다.

게임 시작 시 본인 포지션에서 플레이어 포지션 빼서 상대적 위치를 구함.
그리고 상하좌우 회전값을 곱해 저장한 상대적 위치에서 회전값만 바뀌게 해 플레이어가 뒤를 돌아도 위를 봐도 항상 일정거리 이상 떨어진 상태로 플레이어 따라다니게 함.
이때 플레이어를 바라보는 건 보장되지 않음








---

# Offset(오프셋)

Offset은 **플레이어를 기준으로 카메라가 얼마나 떨어져 있는지를 나타내는 상대 위치 벡터**이다.

게임 시작 시 다음 코드를 통해 계산한다.

```csharp
_offset = transform.position - player.transform.position;
```

여기서

* `transform.position` : 카메라의 현재 위치
* `player.transform.position` : 플레이어의 현재 위치

를 의미하며, 두 위치의 차이를 계산하여 플레이어 기준 카메라의 상대 위치를 저장한다.

---

## 계산 과정

예를 들어 게임 시작 시

| 객체   | 위치         |
| ---- | ---------- |
| 플레이어 | (0, 0, 0)  |
| 카메라  | (0, 3, -6) |

이라면

```text
Offset

=

카메라 위치

-

플레이어 위치

=

(0,3,-6)
```

가 된다.

즉,

```text
플레이어보다

위로 3m

뒤로 6m
```

떨어져 있다는 의미이다.

---

## 왜 Offset을 저장하는가?

만약 Offset을 저장하지 않고

```csharp
transform.position = player.transform.position;
```

처럼 플레이어 위치만 따라가면

```text
플레이어

●

카메라

●
```

두 객체가 같은 위치에 존재하게 되어 화면이 정상적으로 보이지 않는다.

반대로 Offset을 사용하면

```text
카메라
   ●

   ↑ 3m

플레이어 ●

← 뒤로 6m →
```

항상 일정한 거리에서 플레이어를 바라볼 수 있다.

---

## 이동 시 활용

플레이어가 이동하면 Offset은 변하지 않는다.

예를 들어

초기 상태

```text
Player (0,0,0)

Camera (0,3,-6)

Offset (0,3,-6)
```

플레이어가

```text
(10,0,5)
```

로 이동하면

```text
Camera

=

Player

+

Offset

=

(10,0,5)

+

(0,3,-6)

=

(10,3,-1)
```

이 된다.

즉, **플레이어가 어디로 이동하더라도 카메라는 항상 같은 상대 위치를 유지하며 따라간다.**

---

## 회전 시 활용

이 스크립트에서는 Offset을 그대로 사용하는 것이 아니라,

```csharp
Vector3 rotatedOffset = horizontal * vertical * _offset;
```

를 통해 플레이어의 회전에 맞게 Offset을 함께 회전시킨다.

예를 들어 플레이어가 오른쪽으로 90° 회전하면

기존 Offset

```text
(0,3,-6)
```

도 함께 회전하여

```text
(6,3,0)
```

과 같은 방향으로 변한다.

따라서 카메라는 항상 **플레이어의 뒤쪽**에 위치하게 된다.

---

## Offset을 사용하는 장점

* 플레이어와 카메라 사이의 거리를 일정하게 유지할 수 있다.
* 플레이어가 이동해도 자연스럽게 따라오는 카메라를 구현할 수 있다.
* 플레이어의 회전에 맞춰 카메라가 함께 공전하도록 구현할 수 있다.
* 카메라 거리나 높이를 Offset 값만 수정하여 쉽게 조정할 수 있어 유지보수가 용이하다.

즉, **Offset은 "플레이어를 기준으로 카메라가 어디에 위치해야 하는가"를 정의하는 기준 벡터이며, 이동과 회전 시 카메라의 최종 위치를 계산하는 핵심 요소이다.**
